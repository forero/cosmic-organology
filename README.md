# Cosmic Organology

Landing page for *Cosmic Organology* ("Organología de la Cartografía
Cósmica"), an art-science installation by Santiago Reyes Villaveces
(Facultad de Arquitectura y Diseño) and Jaime Forero-Romero (Facultad de
Ciencias), Universidad de los Andes, transducing DESI's baryon acoustic
oscillations into a sculptural piece for **COSMOS 2027** (Sala Colpatria,
julio-agosto 2027).

Static site, no build step: `index.html` + `style.css`. Published with
GitHub Pages from the `main` branch.
